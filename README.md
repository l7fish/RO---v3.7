# RO 放置仙境 - 全能掛機與倉庫販售助手

Tampermonkey 使用者腳本，協助提升《RO 放置仙境》的掛機物品管理效率，提供背包批次設定、掉落物快速分類、消耗品設定同步，以及回村後依設定存倉與販售等功能。

## 🌟 功能特色

- 🦋 **一鍵回村存倉**：嘗試使用背包中的蝴蝶翅膀回城，接著依遊戲目前設定執行倉庫存入與商店販售。
- ⚡ **背包快選與批次設定**：快速選取雜物、卡片及裝備，批次設為【存倉】或【賣出】。
- 🎁 **本圖掉落物快速分類**：列出目前設為【不處理】的掉落物，可逐項調整為不處理、賣出或存倉；完成分類後會從待處理清單消失。
- 🧪 **消耗品與補給設定同步**：在「藥水與補給」區域集中查看可使用消耗品、傳送翅膀及箭矢相關設定，並提供未設定用途的一鍵開啟功能。
- 🔄 **設定即時同步**：面板操作會同步觸發遊戲頁面原有控制項；修改完成後仍須依遊戲介面提示按下「套用設定」。

## 📦 安裝方式

1. 使用支援 Tampermonkey 的瀏覽器，並先安裝 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/)。
2. 開啟下方正式安裝連結：

   **[點此安裝 RO 放置仙境助手 v3.7](https://raw.githubusercontent.com/l7fish/RO---v3.7/main/ro-idle-helper.user.js)**

3. 在 Tampermonkey 安裝頁面確認腳本內容，點選「安裝」。
4. 開啟《RO 放置仙境》，符合腳本網址匹配條件時即可使用。

## 🔄 更新方式

腳本已設定 Tampermonkey 更新來源：

- **自動更新**：Tampermonkey 會依其更新檢查排程，從本專案的 Raw 檔案檢查新版本。
- **手動更新**：開啟 Tampermonkey 儀表板，對此腳本執行「檢查更新」。

正式更新時，請先完成程式碼測試，再修改 `ro-idle-helper.user.js` 標頭中的 `@version`，並將新版提交至 `main` 分支。版本號必須高於使用者目前安裝的版本，更新檢查才會辨識為新版。

## 🛠️ 開發與發佈

主要腳本：[`ro-idle-helper.user.js`](./ro-idle-helper.user.js)

使用者腳本標頭中的更新網址已指向本專案：

```text
https://raw.githubusercontent.com/l7fish/RO---v3.7/main/ro-idle-helper.user.js
```

建議發佈流程：

1. 修改腳本並更新 `@version`。
2. 在測試帳號或可控環境確認頁面元素、存倉及販售流程正常。
3. 確認沒有誤賣或誤存風險後，再提交至 `main` 分支。
4. 發佈後以 Raw 安裝連結確認取得的是最新腳本。

## ⚠️ 使用提醒

- 本腳本依賴遊戲頁面的 DOM 結構與按鈕文字；若遊戲介面更新，部分功能可能需要同步調整。
- 「執行存倉以及販售」會依遊戲內既有設定執行操作。請先確認物品的存倉／販售分類，避免珍貴物品被誤售。
- 本腳本不保證遊戲服務端狀態或操作結果；請以遊戲實際顯示為準。
