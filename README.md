RO 放置仙境 - 全能掛機與倉庫販售助手 (Tampermonkey Script)

一鍵升級《RO 放置仙境》的掛機與倉庫管理體驗，提供精細化物品分類、雙向設定同步與一鍵回村存倉等強大功能。

🌟 主要功能亮點

🦋 一鍵回村存倉：自動使用蝴蝶翅膀回城，並依序完成倉庫存入與商店販售。

⚡ 背包快選與批次設定：在背包介面提供快速選取雜物、卡片與裝備功能，一鍵批次切換為【存倉】或【賣出】。

🎁 本圖掉落物智能過濾：自動篩選出目前設定為【不處理】的掉落物，方便迅速批次設定分類（設定後自動隱藏已處理項目）。

🧪 消耗品與箭矢雙向同步：在「藥水與補給」下方直接雙向同步所有可使用消耗品、翅膀與箭矢，並支援一鍵開啟未設定項目。

📦 安裝步驟

確保瀏覽器已安裝 Tampermonkey (篡改猴) 擴充功能。

點擊下方安裝連結：

🔗 點此直接安裝腳本 (請替換為你的實際 GitHub Raw 連結)

在跳出的 Tampermonkey 畫面中點擊 「安裝」（Install）即可完成。

🔄 如何更新

自動更新：Tampermonkey 會定期在背景檢查最新版本。

手動更新：點擊瀏覽器右上角的 Tampermonkey 圖示 ➔ 點擊 「檢查使用者腳本更新」。

🛠️ 開發者發佈與維護指南

若要對外發佈更新，請在 ro-idle-helper.user.js 中調整版本號：

// ==UserScript==
// @name         RO放置仙境 - 全能掛機與倉庫販售助手
// @version      3.7  <-- 修改此版本號以觸發使用者端自動更新
// ==UserScript==
